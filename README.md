# Spotlight 4

Interactive vocabulary and grammar trainers for *Spotlight 4* (grade 4): picture flashcards with Russian translations and audio, then simple drills with instant checking.

Site: https://elvisk2079-ux.github.io/spotlight-4/

- `m4/` — Module 4 *At the zoo!* vocabulary (animals, adjectives, actions, months, zoo rules, words from the texts)
- `grammar/` — grammar by module (Module 4: Present Simple vs Continuous, comparatives, must / mustn't)
- `src/` — sources and build scripts
